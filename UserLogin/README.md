# User Login Application

A React-based user authentication system built with Vite and Redux Toolkit Query.

## Features
- **User Registration**: Allows new users to create an account via a sign-up form.
- **User Login**: Secure sign-in functionality for registered users.
- **State Management**: Utilizes Redux Toolkit and RTK Query for efficient state handling and API interactions.
- **Routing**: Implements `react-router-dom` for seamless navigation between login and registration pages.
- **Responsive Navigation**: Includes a navigation bar for easy access to application features.

## Tech Stack
- **Frontend**: React 19, Vite
- **State Management**: Redux Toolkit, RTK Query
- **Routing**: React Router DOM
